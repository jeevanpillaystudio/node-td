Depends on: none
Parallel-safe with: none

## Goal
Make `biome lint`, `turbo run typecheck` and `turbo run test` runnable and reproducible before any code changes. This item makes no product behaviour change.

## Steps
- Note for every item: if `bun` is not on PATH, it is at ~/.bun/bin/bun. All commands run from the repository root.
- In .gitignore, delete the `# Bun` / `bun.lock` lines, add `.claude/` and `.tanstack/`, and remove `.nitro/` and `.vinxi/`. Commit the existing bun.lock unchanged. In package.json set "packageManager": "bun@1.3.9". Add bunfig.toml with `[install]` and `linker = "isolated"`. (commit 1)
- Run `./node_modules/.bin/biome migrate --write`. Then in biome.json set css.parser.tailwindDirectives=true, and files.includes=["**", "!**/routeTree.gen.ts", "!**/__snapshots__/**"]. Change the root script to `"lint": "biome lint ."`; formatting and import sorting wait until E1. Fix the a11y/useButtonType errors by adding type="button". For noImplicitAnyLet, noArrayIndexKey and useSemanticElements, make the obvious local fix. For useExhaustiveDependencies, add a `biome-ignore` comment with the reason, and do not change effect dependencies. (commit 2)
- Delete the root tsconfig.json. In internal/typescript/base.json delete `disableSourceOfProjectReferenceRedirect` and the inert `exclude`. (commit 3)
- Remove `**/routeTree.gen.ts` from .gitignore, run `bun run --cwd apps/examples build`, and commit apps/examples/src/routeTree.gen.ts. (commit 4)
- In turbo.json: add `"transit": {"dependsOn": ["^transit"]}`. Change typecheck to dependsOn ["transit"], keeping outputs [".cache/tsbuildinfo.json"]. Add `"test": {"dependsOn": ["transit"], "outputs": []}`. Set build outputs to ["dist/**"]. Delete packages/engine/turbo.json. Add a root script `"test": "turbo run test"`. Add dist and .tanstack to the apps/examples clean script. (commit 5)

## Verification
Each of these must hold:
- `./node_modules/.bin/biome lint .` exits 0.
- `./node_modules/.bin/turbo run typecheck` exits 0 for engine, frame and examples.
- `git ls-files bun.lock bunfig.toml apps/examples/src/routeTree.gen.ts` prints three paths.
- `./node_modules/.bin/turbo run typecheck --dry=json | grep -c '"transit"'` is at least 1.
- `bun run --cwd apps/examples build` exits 0.
- `git diff 22fd93a --stat -- 'packages/**/*.ts' 'packages/**/*.tsx'` shows only the lint-fix lines.

## Risk
Low. A lint fix that changes effect timing would alter Frame behaviour, which is why useExhaustiveDependencies is suppressed rather than fixed. If turbo.json is misconfigured, caches go stale; the --dry check guards this.
