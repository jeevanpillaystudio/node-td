# Work item C3: Make the CPU field path authoritative: remove GPU branches and the _gl side channel

Depends on: S2, S3
Parallel-safe with: C1, C2, C4

## Goal
Browser output equals headless output. This removes the compileField hang on Terrain Heightmap, the per-cook WebGL context leak, the viewport-dependent grid-sampler output, and the untyped env._gl.

## Files
- packages/engine/src/operators/top/grid-sampler.ts
- packages/engine/src/operators/top/field-render.ts
- packages/frame/src/frame.tsx
- packages/frame/src/editor/editor-preview.tsx
- packages/engine/test/boundaries.test.ts

## Steps
- grid-sampler.ts: delete the cols*rows>500 GPU branch (createCanvas + createWebGL2 + renderFieldToBuffer) and its compileField/webgl imports. Keep the CPU loop unchanged.
- field-render.ts: delete getGL and the GPU branch, keep the CPU loop unchanged, and relabel it 'Field Render'.
- frame.tsx: delete _sharedGL/getSharedGL and the `_gl` env key. editor-preview.tsx: delete makeGL and the `_gl` env key.
- Keep render/webgl.ts and kernel/field-compiler.ts. They have no runtime caller now; webgl.ts is the dormant backend for the deferred GPU rasterizer.
- Add packages/engine/test/boundaries.test.ts, which greps packages/engine/src/operators for imports of render/ and fails if any exist.

## Verification
Each of these must hold:
- `grep -rnE '_gl|createWebGL2|compileField|render/webgl' packages/engine/src/operators packages/frame/src` prints nothing.
- `bun test packages/engine` exits 0, with snapshots unchanged (`git status --porcelain -- ':(glob)**/__snapshots__/**'` empty).
- `bun run --cwd apps/examples build` exits 0.
- Optional: look at Terrain Heightmap in the session's built-in preview pane, never Google Chrome.

## Risk
Medium for performance. A CPU field-render at a large panel costs about 1 s per 2.5 Mpx on the main thread (2.9 s measured for 2400×1600). That is acceptable for static images, and the GPU path today hangs instead. Browser output at md widths changes for grid-sampler patches, which is the intended fix: they now match lg widths and the goldens.
