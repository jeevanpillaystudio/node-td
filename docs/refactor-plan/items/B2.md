# Work item B2: Intended change: correct geometric-normal, with the Subscapes light compensated

Depends on: G1
Parallel-safe with: B1, B3, E2, K3

## Goal
Make normals point up and away from slopes, n ∝ (-∂h/∂x, 1, -∂h/∂z), while keeping Subscapes' interior shading identical. The old interior normal was (∂h/∂x, 1, ∂h/∂z). Mirroring the patch light in X and Z gives the same N·L, so only boundary vertices change.

- packages/operators/src/sop/heightfield/__snapshots__/geometric-normal.golden.test.ts.snap

## Steps
- geometric-normal: use central differences on both axes (or one consistent orientation) with the correct sign. Add analytic-plane tests: for h = 0.5x the normal is (-0.447, 0.894, 0) at the interior, at x=0 and at z=0.
- In subscapes-terrain-3d.ts, set the shade light to lightX = +0.5 and lightZ = +0.5 (it was -0.5) and keep lightY. Write the convention down in diffuse-shade: L is the direction light travels, and the term is max(0, N·L).
- Add a test that N·L for interior vertices equals the pre-fix values.
- Re-pin the Subscapes goldens in one commit labelled 'intended output change: normals at tile boundary'. The message gives the count of changed colour draw calls.

## Verification

- `bun test packages/operators packages/patches` exits 0.
- The interior N·L equality test passes.
- The render snapshot diff for subscapes is limited to boundary-vertex colour entries, which you check by reading the diff.
