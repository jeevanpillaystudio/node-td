# Work item B3: Operator bug fixes that leave every gallery render unchanged

Depends on: G1
Parallel-safe with: B1, B2, E2, K3

## Goal
Fix confirmed operator bugs that no gallery patch reaches, each with a unit test.

## Files
- packages/operators/src/sop/merge.ts
- packages/operators/src/sop/transform-2d.ts
- packages/operators/src/sop/quadtree-subdivide.ts
- packages/operators/src/sop/binary-subdivide.ts
- packages/operators/src/comp/camera-2d.ts
- packages/operators/src/top/stroke-renderer.ts
- packages/operators/src/top/composite.ts
- packages/operators/src/sop/camera/visibility-cull.ts
- their colocated golden tests and snapshots

## Steps
- merge: normalise inputs to explicit strips (a missing stripOffsets means one strip), reject mixed dim or topology, and concatenate attributes and colors.
- transform-2d: keep z for geo3 input. Its port type stays geo2 unless a geo3 variant is needed.
- quadtree-subdivide: tile with min(w,h) roots, clip to the canvas, round maxDepth, and emit cellId and depth attributes through a leaf emitter shared with binary-subdivide.
- camera-2d / stroke-renderer: always apply translate(viewport/2)·rotate·scale·translate(-center), so Center X/Y pans. This is identical at the patches' defaults.
- composite: make the CPU blend modes alpha-weighted and premultiplied, matching canvas globalCompositeOperation. Test both paths on transparent and semi-transparent layers.
- stroke-renderer: return an empty image for a non-positive size instead of throwing in getImageData.
- visibility-cull: report an error through the K1 error state for unusable input (points, missing stripOffsets, non-indexed mesh) instead of silently passing it through.
- Re-pin op goldens for these operators only, one commit per operator.

## Verification
Each of these must hold:
- `bun test packages/operators packages/patches` exits 0.
- `git diff --stat -- ':(glob)packages/patches/**/__snapshots__/**'` is empty across all B3 commits.
- `./node_modules/.bin/turbo run typecheck` exits 0.

## Risk
Low. The binary-subdivide leaf-emitter change must keep binary-subdivide's own golden unchanged.

## Orchestrator overrides (added 12 Oct 2026, by hand, after Sol's first read)
- visibility-cull: a line strip without stripOffsets is culled as one strip, not reported as an error. The finding this step addresses (sop/cull-silent-passthrough) recommends normalising such input to explicit strips, and since G1 the geometry model reads a missing stripOffsets as one valid strip (kernel types.ts, forEachStrip). Geometry that is not line strips (points, triangles) and a mesh that is not indexed triangles are errors, as the step says.
- composite: the canvas path is tested by the operations it records, not by pixels. No canvas that rasterises is installed and none can be without registry access, so CPU/canvas pixel parity on transparent and semi-transparent layers is owed: docs/roadmap.md carries it as a check in the browser, in the v0.1 editor work. The CPU path is tested against hand-worked W3C values for all four modes.
