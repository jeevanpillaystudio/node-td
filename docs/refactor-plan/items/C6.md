# Work item C6: Patches registry, removal of continuous-stroke, gallery driven by the registry

Depends on: C5b
Parallel-safe with: K3

## Goal
Make @node-td/patches the single source for the gallery. Drop the identity operator, keeping render output identical.

- packages/patches/src/index.ts
- packages/patches/src/simplex-field.ts
- packages/patches/src/subscapes-terrain-3d.ts

## Steps
- In packages/patches/src/index.ts, export `patches: readonly PatchEntry[]` with {id: graph.id, name: graph.name, kind}. kind is 'artwork' for meridian and subscapes-terrain-3d and 'study' for terrain-heightmap, simplex-field and flow-field. Keep the named exports.
- apps/examples/src/routes/index.tsx: map over `patches` and show labels from graph.name instead of the hand-typed list.
- In simplex-field.ts and subscapes-terrain-3d.ts, remove the `stroke` (continuous-stroke) node and rewire trace→render and trace→lift directly. Delete operators/src/sop/continuous-stroke.ts and its golden test, and remove it from allOperators.
- Patch text fixes: 'Matt Desl' → 'Matt DesLauriers'. Mark meridian's '(fxhash)' provenance as unverified. Rename the subscapes node key `ridge` → `shape`, because it holds field-remap mode 4 (power).
- Run `bun test --update-snapshots packages/patches packages/operators`. Confirm that only node-tier entries changed (the 'stroke' entries removed, ridge→shape renamed) and that render-tier files are byte-identical. Commit as 'test: re-pin node digests after removing identity node (render unchanged)'.

## Verification
Each of these must hold:
- After `bun test packages/patches packages/operators`, `git diff HEAD~1 --stat -- ':(glob)**/__snapshots__/*.render.*'` is empty.
- `git diff HEAD~1 -- ':(glob)packages/patches/**/*.nodes.*'` shows only stroke removals and the ridge→shape renames.
- `grep -rn continuous-stroke packages apps --include='*.ts' --include='*.tsx' --exclude-dir=node_modules` prints nothing.
- `bun run --cwd apps/examples build` exits 0.

## Risk
Low. Removing a node could change the Kahn tie order between RNG consumers. The render goldens would catch that, and checking by hand, the order of the RNG consumers (partitions before seeds) is preserved.
