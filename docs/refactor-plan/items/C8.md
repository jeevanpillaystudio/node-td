# Work item C8: React Flow adapter cleanup: correct auto-layout, one handle-id helper, read-only canvas

Depends on: C7, K1
Parallel-safe with: K2, K3

## Goal
Make the editor adapter correct and honest about what it does. It stays a read-only viewer with an inspector until graph editing exists.

## Files
- packages/editor/src/graph-adapter.ts
- packages/editor/src/editor/gen-node.tsx
- packages/editor/src/editor/editor-canvas.tsx
- packages/editor/src/graph-adapter.test.ts

## Steps
- graph-adapter.ts: autoLayout computes depth by iterating the topoSort order, taking the max over each node's incoming wires.
- Add a single `handleId(nodeKey, 'in' | 'out', port)` helper and use it in both graph-adapter and gen-node.tsx.
- Build the $env node from the kernel's ENV_SOURCE declaration instead of a fake 'top' operator.
- editor-canvas.tsx: set deleteKeyCode={null}, nodesConnectable={false} and edgesReconnectable={false}, and apply only selection and position changes.
- Delete GenEdgeData and NodeLayout if they remain unused.
- Add bun tests: wires [b→c, a→b] give c a column after b; every edge handle id matches a rendered handle id.

## Verification

- `bun test packages/editor` exits 0.
- `./node_modules/.bin/turbo run typecheck` exits 0.
- `grep -rn -- '-out-\|-in-' packages/editor/src --include='*.ts*'` matches only the handleId helper.
