## Steps
- Add `"test": "bun test"` to packages/engine/package.json. Exclude `src/**/*.test.ts` and `test/**` from packages/engine/tsconfig.json, because bun:test types are not installed (T2 may re-include them).
- Create packages/engine/test/support/recording-canvas.ts with RecordingCanvas {width, height, getContext('2d')}. The 2D context records every call and property set that stroke-renderer, composite and blitBuffer2D use: beginPath, moveTo, lineTo, stroke, fill, closePath, arc, fillRect, translate, scale, rotate, drawImage, putImageData, getImageData, strokeStyle, fillStyle, lineWidth, lineCap, lineJoin, globalCompositeOperation, plus save/restore/setTransform defensively. Each entry is [canvasId, name, ...args], with numbers rounded to 1e-3 and canvas arguments replaced by their creation id. getImageData returns zero-filled data. Export createRecordingCanvasFactory() → {createCanvas, log}.
- Create test/support/digest.ts with digest(value) per currency:
- Field2D: a 17×17 lattice over [0,W]×[0,H] → {min, max, mean, hash}.
- Buffer2D: {width, height, channels, stats, hash}.
- Geometry: {dim, topology, vertexCount, stripOffsets hash, indices hash, positions stats+hash, normals hash, attribute name → hash}.
- Palette: {count, colors hash}; weights are excluded.
- Camera2D: its fields.
- Camera3D: project() of 27 lattice points plus unproject() of 3 screen points.
- number.
The hash is FNV-1a 32 over Math.round(v*1e3).
- Create test/support/cook.ts with cookGraph(graph, {width, height, dpr, seed}). It builds createDefaultRegistry(), CookEngine, setParams({}), and env {width, height, dpr, rng: new SeededRNG(seed), createCanvas}, mirroring frame.tsx:136-145 without _gl. It returns {nodes: key→port→Digest, render: {hash, length} of the canvas log, cooked}.
- Restore `git show 33c3b8c:packages/engine/src/patches/meridian.test.ts` to the same path. Change `from "vitest"` to `from "bun:test"` and swap its FakeOffscreenCanvas for RecordingCanvas. Commit.
