# Work item S2: Kernel unit tests that pin today's semantics, with known bugs as test.failing

Depends on: S1
Parallel-safe with: S3, T2

## Goal
Pin the CookEngine, graph, registry, RNG and FieldExpr behaviour that later items move or fix. Known bugs are recorded as `test.failing`, which passes while the bug exists and fails once it is fixed, so the fix must flip the test.

## Files
- packages/engine/src/kernel/graph.test.ts
- packages/engine/src/kernel/cook.test.ts
- packages/engine/src/kernel/rng.test.ts
- packages/engine/src/kernel/field-expr.test.ts

## Steps
- graph.test.ts:
- topoSort order and the cycle error.
- A wire to an unknown node. Pin the TypeError now; add a test.failing 'reports unknown node by name'.
- validateGraph: one case per error class.
- test.failing '$env wires are type-checked'.
- collectParams key prefixing and defaults.
- cook.test.ts, using fake operators in a fresh OperatorRegistry:
- The dirty set after setParams for changed, added, removed and unchanged keys.
- Downstream-only propagation.
- A width change dirties only $env dependents.
- Param precedence: default < instance < external.
- Variadic inputs keep wire order.
- A clean node returns the same cached object.
- test.failing: setParams copies its argument (in-place edit detected).
- test.failing: a dpr change re-cooks dpr readers.
- test.failing: a throwing node does not stop independent branches.
- test.failing: validateGraph runs in the constructor.
- test.failing 'incremental cook equals full cook with two rng nodes': two circle-pack nodes, change b.margin and change it back.
- rng.test.ts:
- The first 5 draws for SeededRNG(42) and SeededRNG('abc').
- test.failing 'fork is a pure function of (seed, tag)'.
- field-expr.test.ts:
- evalExpr golden values per FieldExpr tag at 5 fixed points.
- pnoise and simplex2 golden values at 10 points.
- createField/getFieldExpr round trip.

## Verification
Each of these must hold:
- `bun test packages/engine/src/kernel` exits 0.
- `bun test packages/engine/src/kernel 2>&1 | grep -c '(fail)'` prints 0.
- `grep -c 'test.failing' packages/engine/src/kernel/*.test.ts` lists the expected known-bug tests.

## Risk
Low. Golden values for RNG and noise are taken from current code, which is intended: they pin, not judge.
