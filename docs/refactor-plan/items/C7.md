# Work item C7: Split @node-td/frame (runtime) from @node-td/editor (dev); fix ResizeObserver double cook and Tailwind scanning

Depends on: C6
Parallel-safe with: K3

## Goal
Make the production renderer depend only on the engine layers and React, and make the editor a separately styled dev package that the app opts into.

## Files
- packages/frame/**
- packages/editor/**
- packages/render-web/src/canvas-2d.ts
- apps/examples/src/routes/index.tsx
- apps/examples/src/routes/__root.tsx
- apps/examples/src/styles/app.css
- apps/examples/package.json
- bun.lock

## Steps
- Create packages/editor (@node-td/editor, tag layer-ui). git mv packages/frame/src/{editor/*, frame-provider.tsx, frame-shell.tsx, ui/*} into packages/editor/src. Move the @xyflow/react, radix, cva, clsx and tailwind-merge dependencies from frame to editor. Trim Button to the ghost/sm variant, dropping Slot.
- In frame, add src/frame-host.ts with FrameHostContext {register(entry), unregister(id), renderOverlay?(id): ReactNode}. Frame uses only this context, uses inline styles (wrapper `position: relative`), drops cn, and takes optional `registry` (default defaultRegistry()) and `seed` props. The editor's FrameProvider implements FrameHostContext and renders the selection outline and the 'Edit Graph' button through renderOverlay, with a non-interactive outer element.
- Change FrameShell to take an `enabled` prop. apps/examples passes `import.meta.env.DEV`. Remove process.env and @types/node from frame and editor.
- Frame drawing:
- Create the ResizeObserver once per mount in its own effect; it records size and dpr and schedules a draw only when they change.
- The values/graph/visibility effect schedules exactly one rAF draw.
- Remove the `_mountOrder` stagger global.
- Keep `engine.clearCache()` after each draw for now.
- Return early when width or height is 0.
- Wrap the draw in try/catch, and show an error state when cooking throws or no terminal output exists.
- Add an error boundary around Frame's contents.
Apply the same single-observer pattern to the editor preview.
- Delete drawCanvas2D from render-web and the geometry-terminal fallbacks in Frame and EditorPreview. EditorPreview uses graph-adapter and the same seed as Frame (42) until K2 moves the seed onto the graph.
- Styles:
- Add packages/editor/styles.css with `@source "./src";` and default @theme tokens (card, ring, muted, border, primary, accent, secondary, input), exported as "./styles.css".
- apps/examples/src/styles/app.css imports it. If package-export resolution fails in @tailwindcss/vite, use `@source "../../../../packages/editor/src";` in app.css instead.
- Fix the edge stroke to `var(--color-border)`.
- Unquote the generic font keywords in app.css, and remove the unused `dark` class from __root.tsx.
- Give the editor package the useful headless tests: graph-adapter handle ids and layout under bun.

## Verification
Each of these must hold:
- `grep -cE 'xyflow|radix|tailwind|clsx|class-variance' packages/frame/package.json` prints 0.
- `grep -rnE 'process\.env|\bcn\(|@node-td/editor' packages/frame/src` prints nothing.
- `./node_modules/.bin/turbo run typecheck test` exits 0, and `./node_modules/.bin/turbo boundaries` reports no issues.
- `bun run --cwd apps/examples build` exits 0.
- `grep -lE '\.w-60|\.bg-card|\.z-50' apps/examples/dist/client/assets/*.css` matches a file.
- `grep -l react-flow apps/examples/dist/client/assets/*.js` matches nothing.
- Golden snapshots are unchanged.
- Optional: check one draw per resize in the session's built-in preview pane (never Google Chrome).

## Risk
Medium. The ResizeObserver and draw scheduling changes cannot be covered headless, so review them carefully and keep clearCache so images cannot change. Splitting the context API touches every editor component.
