# Work item S3: Two-tier golden characterization of every gallery patch and every operator

Depends on: S1
Parallel-safe with: S2, T2

## Goal
Commit snapshots, taken from current behaviour, that every later item is checked against. Render tier: the recorded canvas command stream for each patch, which is what 'renders the same' means headless. Node tier: a digest of every node output. Op tier: one small fixture graph per operator.

## Files
- packages/engine/src/patches/*.golden.test.ts
- packages/engine/src/patches/__snapshots__/*
- packages/engine/src/operators/**/*.golden.test.ts
- packages/engine/src/operators/**/__snapshots__/*
- packages/engine/test/support/op-golden.ts

## Steps
- For each of meridian, subscapes-terrain-3d, terrain-heightmap, simplex-field and flow-field, create src/patches/<id>.render.golden.test.ts and src/patches/<id>.nodes.golden.test.ts. They cook with cookGraph at 256×256, 400×400, 800×800 and 640×400 with dpr 1, plus 400×400 with dpr 2, all at seed 42. They snapshot render {hash, length} and nodes respectively with toMatchSnapshot(). One file per patch and tier keeps later items' snapshot edits disjoint.
- For every registered operator, create a colocated <op>.golden.test.ts, for example operators/sop/merge.golden.test.ts, using a shared opGolden(op, fixtureGraph) helper in test/support. Each fixture is the smallest graph that exercises the operator, with variants for code-path params: every field-remap mode, every stroke-renderer renderMode, every composite mode, fbm domainRotation 0 and 0.646, and merge with mixed strip offsets. Include the 8 operators no patch uses.
- Generate the snapshots, run the suite a second time, and confirm there is no diff. Commit the snapshots alone as 'test: pin current behaviour (golden baseline)'.

## Verification
Each of these must hold:
- `bun test packages/engine` exits 0.
- A second `bun test packages/engine` leaves `git status --porcelain -- ':(glob)**/__snapshots__/**'` empty.
- `time bun test packages/engine` stays under 60 s.
- `git show --stat HEAD` lists only test and snapshot files.

## Risk
Medium.
- The snapshots must be taken from unchanged 22fd93a engine code (T1 touches only lint lines in frame).
- Last-bit Math differences between macOS and Linux could flip a quantised value inside chaotic loops (raymarch, flow tracing). Treat macOS as authoritative and run golden tests on a macOS CI runner (E3).
