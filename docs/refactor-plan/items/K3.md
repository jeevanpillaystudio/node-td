# Work item K3: Fix compileField: termination, declaration order, number literals

Depends on: C5a
Parallel-safe with: C5b, C6, C7, C8, K1, K2, K4, K5, K6a, K6b, G1, B1, B2, B3

## Goal
Make the GLSL emitter a correct, tested pure function, ready for the deferred GPU rasterizer. Nothing calls it at runtime after C3, so this carries no behaviour risk.

## Files
- packages/kernel/src/field/glsl.ts
- packages/kernel/src/field/glsl.test.ts

## Steps
- In genFunctions/genExprAsBody, stop deleting and re-inserting the entry being defined. Pass the expression being defined as an excluded 'self'.
- Iterate a fixed list in post order, where callees come before callers. Assign a function name only after its children have been analysed.
- glFloat: always emit a mantissa with '.', handle exponent form (1e-7 → 1.0e-7), and throw on non-finite values. Emit unary minus as `(-(e))`.
- Inject hashGrad only when Perlin is used. Bind repeated div and warp sub-expressions to temporaries.
- Add field/glsl.test.ts, run with a 5 s timeout. It checks that compileField terminates and returns source for the FieldExpr of every field operator fixture and of every patch's field chain (collected with getFieldExpr from a cook). It checks that no field_fn_N is referenced before it is defined, and covers literal formatting.

## Verification
Each of these must hold:
- `bun test --timeout 5000 packages/kernel/src/field` exits 0.
- `./node_modules/.bin/tsc --noEmit -p packages/kernel` exits 0.
- `git status --porcelain -- ':(glob)**/__snapshots__/**'` is empty.

## Risk
Low. Nothing calls it at runtime. If K3 runs in parallel with C5b, the test that gathers patch field chains needs patches and operators: use only operator fixtures until C5b lands.
