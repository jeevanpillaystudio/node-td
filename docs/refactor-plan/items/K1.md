# Work item K1: Kernel invariants: validate on construction, declared $env, per-node error isolation

Depends on: C7
Parallel-safe with: K3

## Goal
Reject invalid graphs early and by name. One failing operator no longer aborts unrelated branches. Valid graphs cook exactly as before.

## Files
- packages/kernel/src/env.ts
- packages/kernel/src/graph.ts
- packages/kernel/src/cook.ts
- packages/kernel/src/index.ts
- packages/kernel/src/*.test.ts
- packages/frame/src/frame.tsx
- packages/editor/src/editor/editor-preview.tsx

## Steps
- Add packages/kernel/src/env.ts: ENV_SOURCE = "$env" with declared outputs {width: number, height: number} and helpers (isEnvSource, envOutputType).
- validateGraph:
- Check $env wires against the declared outputs and types.
- Reject node keys that contain '.' or start with '$'.
- Reject wires to or from unknown nodes before topoSort.
- Report cycles with node names.
- Report unknown operator types.
Run it in the CookEngine constructor, which throws GraphValidationError listing every issue.
- setParams copies its argument ({...params}). cook() returns a ReadonlyMap view.
- Extract a private cookNode(key, env), which gathers inputs, resolves params and calls evaluate, so a future time-sliced cook can reuse it.
- Catch errors per node: record {error} for the node, skip its descendants (recorded as skipped), keep cooking independent branches, and expose stats.errors. A node that errored stays dirty for the next cook.
- Flip the S2 tests (validation, aliasing, isolation) from test.failing to test. Add an isolation test: in subscapes cooked without createCanvas, normals/cull/proj/shade still cook while the renderers report errors.
- Frame and EditorPreview log stats.errors and show the error state from C7.

## Verification
Each of these must hold:
- `bun test packages/kernel` exits 0.
- `grep -n 'test.failing' packages/kernel/src/*.test.ts` lists only the RNG/env items that K2 handles.
- `./node_modules/.bin/turbo run typecheck test` exits 0, with snapshots unchanged (all 5 patches validate).

## Risk
Low. All shipped graphs already pass validateGraph (audit probe). The error isolation path changes only failure behaviour.
