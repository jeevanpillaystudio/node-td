# Work item K5: defineOperator helper, param lint and range widening

Depends on: K4
Parallel-safe with: K3

## Goal
Let the kernel type operator params and inputs, check every param against its declaration, and make every authored patch value legal and reachable in the inspector.

## Files
- packages/kernel/src/define.ts
- packages/kernel/src/graph.ts
- packages/kernel/src/cook.ts
- packages/kernel/src/*.test.ts
- packages/operators/src/field/{simplex-noise,perlin-noise}.ts
- packages/operators/src/sop/{flow-tracer,poisson-disc}.ts
- packages/operators/src/sop/heightfield/geometric-normal.ts

- packages/operators/src/top/composite.ts
- packages/operators/src/sop/camera/visibility-cull.ts
- packages/operators/src/params.test.ts

## Steps
- Add kernel/src/define.ts: defineOperator() with const generics that derives Inputs from PortDefs (optional → T | undefined, variadic → T[]) and Params from ParamDef keys. The type is erased only at the registry boundary. The cook passes [] for unwired variadic inputs; S3's op goldens prove each consumer behaves the same.
- Add lintParams to validateGraph: an unknown param key, a value outside [min, max], an enum value that is not an option, and op defaults outside their own range.
- Widen ranges so every authored value is legal, and make the matching ParamDef edits:
- simplex-noise and perlin-noise noiseScale min 1e-4;
- flow-tracer numSteps min 1;
- poisson-disc minRadius min 1 (min 0 throws RangeError, so it stays ≥ 1);
- geometric-normal epsilon min 1e-6;
- procedural-palette count min 1.
Make composite.mode an enum (same numeric values) and visibility-cull bypass an enum Off/On.
- Tests: every patch lints clean; every op default is within range.

## Verification
Each of these must hold:
- `bun test packages/kernel packages/operators packages/patches` exits 0.
- `./node_modules/.bin/turbo run typecheck` exits 0.
- Snapshots are unchanged, because ranges do not affect cooking.

## Risk
Low or medium. Passing [] instead of undefined for unwired variadics could change an operator's branch; the op goldens catch this.
