# Work item K4: Adopt the taxonomy: categories and sharper port types

Depends on: K2, C8
Parallel-safe with: K3

## Goal
Make family labels and port types say what flows on a wire, so wrong wiring (2D into 3D ops, an RGBA render into flow-tracer) fails validation. Behaviour is unchanged.

## Files
- packages/kernel/src/types.ts
- packages/operators/src/**/*.ts
- packages/operators/src/taxonomy.test.ts
- packages/frame/src/frame.tsx
- packages/editor/src/editor/editor-preview.tsx
- packages/editor/src/editor/gen-node.tsx

## Steps
- kernel/types.ts:
- OperatorCategory = 'field' | 'top' | 'sop' | 'chop' | 'mat' | 'comp'.
- PortType = 'field' | 'image' | 'grid' | 'geo2' | 'geo3' | 'palette' | 'camera2d' | 'camera3d' | 'number'.
- Update every operator's category and port types per the taxonomy map. Port names stay unchanged, so patches need no edits. merge is geo2.
- Run `git mv field/curl-noise.ts field/curl-angle.ts` (with its golden test and snapshot) and change its id to 'curl-angle'.
- Frame and editor look up the terminal output with type 'image'. Update gen-node's category colour map to field/top/sop/chop/mat/comp, using TD-like colours (TOP purple, CHOP green, SOP blue, MAT yellow, COMP grey, FIELD teal).
- Add packages/operators/src/taxonomy.test.ts: every registered op's category matches its primary output type (field→field, image/grid→top, geo2/geo3→sop, palette→chop, camera2d/camera3d→comp; mat is allowed only for diffuse-shade). All patches validate.

## Verification
Each of these must hold:
- `grep -rnE 'type: "(buffer|geometry|camera|signal)"|category: "rop"' packages/operators/src packages/kernel/src` prints nothing.
- `./node_modules/.bin/turbo run typecheck test` exits 0, with snapshots unchanged, apart from the curl-noise→curl-angle op snapshot moving with git mv.

## Risk
Low. If a patch turns out to wire a 2D/3D mismatch, the validation failure is a real bug: record it rather than loosen the type.
