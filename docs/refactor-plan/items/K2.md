# Work item K2: Typed environment and deterministic randomness through RNG stream replay

Depends on: K1
Parallel-safe with: C8, K3

## Goal
Make an incremental cook produce exactly what a full cook produces, without changing any full-cook output. Make the seed part of the graph and the dpr reads part of dirty tracking.

Design decision: the engine keeps one RNG stream drawn in topological order, because that is what produced every finished patch. It records each node's RNG state before and after it cooks. A clean node whose recorded start state equals the current stream state is skipped by restoring its end state; otherwise it re-cooks. This preserves every image. Per-node seeds, the TouchDesigner model, would change every random patch and are deferred.

## Steps
- kernel/types.ts:
- Split GraphEnv into EnvValues {width, height, dpr, seed: number | string} and Capabilities {createCanvas?}.
- The per-node env passed to evaluate is {...values, ...capabilities, rng: NodeRng}, where NodeRng exposes random() only.
- Add Operator.envReads?: ('width' | 'height' | 'dpr' | 'seed')[].
- kernel/rng.ts: add getState()/setState(); delete fork.
- kernel/cook.ts:
- setEnv(values, capabilities) diffs the declared values and dirties $env dependents plus operators whose envReads include a changed key. needsCook becomes accurate.
- cook(env) = setEnv + run.
- The engine creates SeededRNG(seed) at the start of each run and walks the topological order. For each node it records startState/endState around evaluate. For a clean node: if its recorded startState equals the current state, set the state to endState and skip; otherwise mark it and its descendants dirty and cook it.
- kernel/graph.ts: add an optional Graph.seed.
- Operators:
- stroke-renderer and field-render declare envReads ['dpr'] and drop their `as` casts.
- poisson-disc, circle-pack, dash-stroke and binary-subdivide use env.rng and drop the Math.random fallbacks.
- Frame and EditorPreview pass {seed: graph.seed ?? 42} instead of an rng instance. The gallery output is identical to today's SeededRNG(42); the preview now matches the gallery.
- Tests:
- Flip the S2 test.failing items for rng, dpr and fork to test.
- Property test: for each gallery patch at 256 px, apply 20 random in-range param edits with incremental cooks, then compare every node digest against a fresh full cook with the same params.
- A seed change re-cooks exactly the RNG-consuming nodes and their descendants.
- A dpr change re-cooks stroke-renderer and field-render.

## Verification

- `grep -rn 'test.failing' packages/kernel/src` prints nothing, apart from K3's file if it has none.

- After the tests, `git status --porcelain -- ':(glob)**/__snapshots__/**'` is empty, because full-cook output is byte-identical.

## Risk
Medium. The replay logic is subtle around errors, so a node that errored stays dirty and replays from its own start state. RNG output still depends on node insertion order (Kahn tie-break). That is documented and pinned; per-node seeds are deferred.
